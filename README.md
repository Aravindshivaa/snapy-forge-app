# Snapy Forge

Snapy Forge is a dark neon Android utility for extracting high-quality screenshots/frames from videos.

It is built for creators, editors, and users who need a simple mobile workflow for grabbing frames from videos, including high-resolution footage.

## Features

- Select video from Android storage
- Read video duration and resolution
- Choose start time, end time, and frame count
- Export frames as PNG or JPEG
- Choose output folder
- Auto 8K Safe extraction mode
- Friendly in-app error dialogs
- Face Match mode for finding frames that visually match a reference face
- Animated dark/purple landing UI
- Seasonal snow easter egg in December and January

## Download

Download the latest APK from the GitHub Releases page.

`Snapy-Forge-easter-stable.apk`

## Install

1. Download the APK on your Android device.
2. Open the APK file.
3. If Android asks, allow installation from your browser or file manager.
4. Install and open Snapy Forge.

## Privacy

Snapy Forge processes selected videos and images locally on your device. It does not upload your videos, images, extracted frames, or face reference images to any server.

See [PRIVACY_POLICY.md](PRIVACY_POLICY.md).

## Notes

Some video formats, codecs, and 8K files depend on the phone's hardware decoder and memory. If export fails, try:

- Auto 8K Safe mode
- Fast Native mode
- JPEG output
- Fewer frames
- Shorter time range
- A lower-resolution copy of the video
